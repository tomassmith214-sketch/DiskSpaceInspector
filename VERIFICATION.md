# Проверка MVP

Проверено 19 сентября 2026 года на Windows 10, .NET SDK 9.0.203, Desktop Runtime 8.0.15. Целевой framework приложения: `net8.0-windows`.

- Release-сборка и публикация приложения выполнены успешно.
- 40 тестов xUnit прошли: размеры, категории, риски, агрегация, reparse-атрибуты, отмена до/во время обхода, исчезнувшие каталоги, запрет подкаталога вместо корня диска, экранирование CSV/HTML и структура JSON.
- Отдельно создан настоящий NTFS junction в тестовой папке проекта. Сканер прочитал локальный файл размером 1 байт, пропустил ссылку и не включил 1024 байта её цели.
- Полный повторный обход C: завершился без отмены за 39,75 секунды: 1 154 935 файлов, 205 386 папок, 181 228 769 901 байт (168,78 GB), 709 ошибок доступа / пропусков. Первый, менее прогретый обход занял примерно 82 секунды. Это измерения конкретного компьютера, не гарантия скорости.
- Сумма размеров папок в корне совпала с агрегатами категорий и расширений. В файловой таблице сохранено 50 000 крупнейших файлов.
- В WPF проверены все шесть вкладок, пустое состояние, тёмная/светлая темы, окно шириной 1120, поиск, минимум 100 MB и числовая сортировка по возрастанию на реальных данных. Ошибок WPF-привязок не обнаружено.
- Проверены реальные команды «Сканировать C:\» и «Остановить». В проверке частичные результаты опубликованы через 100 мс после остановки. Время зависит от системного вызова, который выполняется в момент отмены.
- Исходники приложения проверены на операции записи/изменения. Единственная запись — новый отчёт в `ExportAsync` после выбора папки. Единственный внешний процесс — Explorer по клику. Функций удаления, переноса, изменения содержимого, ACL или реестра в `src` нет.

Скриншоты проверки и краткий итог обхода находятся в `artifacts/real-c`. Это локальные тестовые артефакты с путями этого компьютера; они не включены в публикацию приложения. Внешний диалог экспорта не автоматизировался; содержимое отчётов проверено тестами.

## Повторение визуальной проверки

```powershell
dotnet run --project tools/VisualSmoke -c Release -- artifacts/ui
dotnet run --project tools/VisualSmoke -c Release -- artifacts/real-c --scan-c
```

Без `--scan-c` экраны заполняются тестовыми данными. Инструмент сохраняет изображения в папку проекта и закрывает своё окно. В конце обоих режимов выполняется короткая проверка сканирования C: и отмены. Тестовые операции записи существуют только в проектах проверки, не в поставляемом приложении.
